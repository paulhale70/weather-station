# weather-station

A DIY home weather station: sensors outside, readings logged and shown on a local dashboard.

Status: just started (6 Nov 2026). Hardware not chosen yet.

## Plan (draft)

1. Pick the hardware (microcontroller and sensors).
2. Read the sensors and send the readings to the PC or a small server.
3. Log the readings (SQLite or CSV).
4. Build a dashboard showing current conditions and history.
5. Optional: alerts (frost, high wind, heavy rain) and a Tool Launcher entry.
